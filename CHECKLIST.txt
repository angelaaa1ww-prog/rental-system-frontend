PHASE 1: SETUP (30 minutes)
═══════════════════════════════════════════════════════════════════════════════

□ STEP 1.1: Get Google Client ID
  • Open: https://console.cloud.google.com/
  • Create new project: "PropertyFlow"
  • Enable Google+ API
  • Create OAuth 2.0 credentials (Web application)
  • Add authorized origin: http://localhost:3000
  • Copy Client ID (long string)
  ⏱️  ~10 minutes

□ STEP 1.2: Create .env File
  • Location: C:\Users\angel\OneDrive\Desktop\rental_system\frontend
  • File name: .env (with the dot, no extension)
  • Paste this (replace the bold part with your Client ID):
    
    REACT_APP_GOOGLE_CLIENT_ID=PASTE_YOUR_CLIENT_ID_HERE
    REACT_APP_API_URL=http://localhost:3001/api
    REACT_APP_ENV=development
    REACT_APP_ENABLE_IP_VERIFICATION=true
    REACT_APP_ENABLE_TERMS_MODAL=true
    REACT_APP_ENABLE_PARTICLE_EFFECTS=true
    REACT_APP_AUTHORIZED_EMAIL=isowekesa@gmail.com
    REACT_APP_POLICY_VERSION=2026-07-07
  
  • Save and close
  ⏱️  ~2 minutes

□ STEP 1.3: Install Dependencies
  • Open Command Prompt (Windows Key + R, type cmd)
  • Paste and press Enter:
    cd C:\Users\angel\OneDrive\Desktop\rental_system\frontend
  
  • Paste and press Enter:
    npm install
  
  • Wait 5-10 minutes (lots of text, that's normal)
  ⏱️  ~10 minutes

PHASE 5: FINAL CONFIGURATION (5 minutes) - REQUIRED!
═══════════════════════════════════════════════════════════════════════════════

□ STEP 5.1: Add Your Live Domain to Google
  
  • Go to: https://console.cloud.google.com/
  • Find your "PropertyFlow" project
  • Go to: APIs & Services → Credentials
  • Find: OAuth 2.0 Client ID (Web application)
  • Click: Edit (pencil icon)
  
  • Under "Authorized JavaScript origins", add:
    □ https://your-app-name.vercel.app
       (or https://your-app-name.netlify.app)
    □ https://your-app-name.vercel.app/
       (or https://your-app-name.netlify.app/)
  
  • Under "Authorized redirect URIs", add:
    □ https://your-app-name.vercel.app
    □ https://your-app-name.vercel.app/
  
  • Click: SAVE
  
  ⏱️  ~3 minutes

□ STEP 5.2: Test Your Live App
  • Visit your live URL
  • Accept terms
  • Click Google Sign-In
  • Verify it works
  ✅ Your live app is working!
