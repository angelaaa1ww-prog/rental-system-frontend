# ✅ SETUP GOOGLE SIGN-IN - COMPLETE GUIDE

Your Google Sign-In button is now fixed and redesigned! Follow this guide to make it work.

## 3 Easy Steps:

### STEP 1: Add your Google Client ID to .env
Location: `C:\Users\angel\OneDrive\Desktop\rental_system\frontend\.env`

```
REACT_APP_GOOGLE_CLIENT_ID=YOUR_CLIENT_ID_HERE
REACT_APP_API_URL=http://localhost:3001/api
REACT_APP_ENV=development
```

(Replace `YOUR_CLIENT_ID_HERE` with your actual Client ID from Google Cloud Console)

### STEP 2: Open Command Prompt & Install

```
cd C:\Users\angel\OneDrive\Desktop\rental_system\frontend
npm install
```

Wait 5-10 minutes.

### STEP 3: Run the App

```
npm start
```

Wait 2-3 minutes. Browser opens to http://localhost:3000

## DON'T SEE THE BUTTON?

### Check:
- [ ] Google Sign-In script loaded? (Check: Press F12 → Console → no red errors)
- [ ] Client ID is in .env? (Open .env file → REACT_APP_GOOGLE_CLIENT_ID is there)
- [ ] Is app running? (Check: URL bar shows http://localhost:3000)
- [ ] Scroll down? (Button is in the middle of the page)

### Try:
- [ ] Hard refresh: Ctrl + Shift + R
- [ ] Clear cache: F12 → Application → Clear storage
- [ ] Restart app: Stop npm, then npm start again

## ISSUES?

**"Can't load script"**
- Your internet connection works? (Google's script needs internet)

**"Client ID is invalid"**
- Copy the full Client ID from Google Cloud Console
- No spaces at beginning or end
- Check .env file has no extra quotes

**"Email not authorized"**
- Make sure using: isowekesa@gmail.com
- Only this email can login

**Browser shows error**
- Press F12 (Developer Tools)
- Go to Console tab
- Show me the red error message
