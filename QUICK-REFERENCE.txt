═══════════════════════════════════════════════════════════════════════════════
                            TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ Problem: "npm: command not found"
✅ Solution: Install Node.js from https://nodejs.org/ (LTS version)

❌ Problem: ".env not working"
✅ Solution: 
   • File must be named exactly: .env (with dot)
   • No .txt extension
   • Restart app after creating

❌ Problem: "Port 3000 is in use"
✅ Solution: 
   • Stop other apps using port 3000
   • Or use: PORT=3001 npm start

❌ Problem: "Cannot find module"
✅ Solution:
   • Delete node_modules folder
   • Delete package-lock.json
   • Run: npm install (again)

❌ Problem: Google Sign-In button not showing
✅ Solution:
   • Check .env has correct Client ID
   • Restart app: npm start
   • Hard refresh browser: Ctrl + Shift + R
